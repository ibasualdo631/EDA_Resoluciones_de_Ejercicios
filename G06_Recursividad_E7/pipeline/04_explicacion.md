## 4. Respuesta: Pregunta de Examen: 
Uso del operador módulo en recursividadPregunta:En el contexto de la extracción recursiva de dígitos, ¿qué rol exacto cumple el operador módulo (n % 10) frente a la división entera (n / 10), y qué falla lógica crítica se produciría si intentáramos aislar el caso recursivo omitiendo el módulo y sumando simplemente n + sumarDigitos(n / 10)

## 5. Respuesta:
El operador módulo (n % 10) tiene el rol exclusivo de aislar atómicamente la unidad menos significativa del número en el marco de ejecución actual, ignorando su magnitud total. La división entera (n / 10), en cambio, es el mecanismo de convergencia, responsable de achicar progresivamente el parámetro en cada invocación recursiva para garantizar que la ejecución choque contra el caso base y evite un StackOverflowError.   Si se omitiera el módulo y la línea fuera return n + sumarDigitos(n / 10);, se perdería la extracción individual del dígito. En el Call Stack, en lugar de sumar 4 + 3 + 2 + 1, el algoritmo arrastraría y acumularía la magnitud residual entera en cada paso de la fase de ascenso, resolviendo 1234 + 123 + 12 + 1 = 1370. El módulo funciona como una "máscara" algorítmica obligatoria para desglosar el número sin alterar la tasa matemática de reducción del problema.
