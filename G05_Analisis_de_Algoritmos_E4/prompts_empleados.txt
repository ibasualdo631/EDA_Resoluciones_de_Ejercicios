Analista: Actúa como Analista de Algoritmos. Analiza el Ejercicio 4: "Detectar elementos duplicados en un vector".

Tareas obligatorias:
1. Desglosa y contrasta las dos estrategias requeridas:
   - Estrategia A (Fuerza Bruta / Ciclos Anidados): Compara cada elemento i con los elementos j (desde i + 1 hasta n - 1). Identifica su dependencia exclusivamente de comparaciones in-place sin memoria extra.
   - Estrategia B (Estructura Hash / HashSet): Recorre el arreglo una sola vez insertando en una tabla hash y detecta el duplicado si set.add() retorna false (o si set.contains() es true).
2. Analiza el Trade-off de Ingeniería fundamental:
   - Tiempo vs. Espacio (CPU vs. RAM): Estrategia A sacrifica tiempo de procesamiento O(n²) para mantener memoria plana O(1). Estrategia B optimiza el tiempo a O(n) sacrificando memoria adicional O(n) para la tabla de dispersión.
3. Identifica los casos límite (Edge Cases):
   - Vector sin duplicados (peor caso temporal para ambos enfoques).
   - Duplicado en las dos primeras posiciones (mejor caso Ω(1) con corte anticipado).
   - Duplicado en los extremos (índice 0 e índice n - 1).
   - Vector con un único elemento o vacío (length <= 1: imposible que haya duplicados).
   - Manejo de arreglo nulo (null).
4. Redacta el borrador del Prompt Técnico Inicial para el Planificador y el bloque de cabecera de la entrega.
